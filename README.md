# Análise do Mercado de Trabalho em TI no Brasil (2023–2024)

## Sobre o projeto
Análise das movimentações de emprego em tecnologia da informação
no Brasil, usando dados públicos do CAGED/MTE.

## Ferramentas utilizadas
- SQL (BigQuery) — extração dos dados
- Python (pandas) — limpeza e tratamento
- Power BI — dashboard interativo

## Principais descobertas
- Desenvolvedor Sênior tem o maior salário médio: R$ 14.464
- SP concentra o maior volume de admissões em TI do país
- Apenas 23% dos admitidos em TI são mulheres
- Mestrado/Doutorado tem salário médio 4x maior que ensino médio completo

## Fonte dos dados
Ministério do Trabalho e Emprego — CAGED
https://basedosdados.org/dataset/br-me-caged
